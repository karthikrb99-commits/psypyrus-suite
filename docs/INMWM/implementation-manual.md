# INMWM Implementation Manual

This file will later hold the operational annexes for the Indian National Mental Wellness Mission.

## Planned annexes

- intake and assessment SOPs
- MSE and documentation standards
- supervision and internship rules
- licensing and chartered-status workflows
- referral and collaboration pathways
- fee-band and insurance workflows
- complaint, misconduct, and whistle-blower workflows
- digital interoperability and data-governance standards
- KPI and dashboard definitions
- implementation roadmaps for Union, State, District, and institutional levels

## Immediate use

Use this manual as the bridge between policy and product implementation. Any future feature that touches clinical workflow, workforce planning, recruitment, or digital records should check this manual first.
