# Indian National Mental Wellness Mission (INMWM)

This directory contains the policy and implementation blueprint for the Indian National Mental Wellness Mission.

## Contents

- `blueprint.md` — the master national reform blueprint
- `implementation-manual.md` — operational standards, workflows, and governance notes
- `references.md` — source map and citation index
- `careeros-bridge.md` — how the mental-wellness mission aligns with the CareerOS framework

## Purpose

INMWM is the policy layer for the broader mental-health operating system. It defines the education, licensing, workforce, governance, workflow, financing, and digital-public-infrastructure standards that should inform both PsyPyrus and companion projects such as CareerOS.
