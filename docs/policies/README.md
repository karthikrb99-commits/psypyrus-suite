# Policy Index

This directory contains the governance layer for the PsyPyrus Suite repository.

## Purpose
These documents complement the Apache 2.0 code licence by defining:
- fair usage expectations
- clinical safety boundaries
- branding and trademark restrictions
- commercial use conditions
- derivative-work and rebrand rules

## Files
- `fair-usage-policy.md` — platform usage limits, abuse controls, and clinical safeguards
- `licensing-and-derivatives.md` — fork, port, clone, white-label, and rebrand boundaries
- `branding-and-trademark-policy.md` — brand identity, attribution, and trademark handling
- `commercial-use-terms.md` — commercial deployment, SaaS, and enterprise use conditions

## Policy posture
PsyPyrus is intended to support a public-good mental-health infrastructure mission. It may be adapted and extended only within the applicable licence and with required attribution, notices, and safety obligations preserved.

## Repository note
If a downstream deployment removes notices, strips attribution, or misrepresents affiliation, that is outside this policy unless explicitly authorized in writing.
